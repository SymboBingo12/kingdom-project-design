# Components

Ready-made pieces built only from `tokens/tokens.css`. To be added once the colours are final:

| Component | Used for |
|---|---|
| Top bar | App name, subtitle, status and the current time |
| Button (primary, secondary) | Main and other actions |
| Card | Grouping related controls |
| List row | Meeting parts and settings, with a "current" state |
| Switch | On/off options |
| Banner | Problems and notices, never colour-only |
| Stage display | The big countdown, warnings and between-parts clock |

Each component will have its own `.css` file and a short example in `examples/`.
