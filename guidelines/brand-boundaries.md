# Brand boundaries

Our apps should feel familiar to JW Library users, but must never look official. The repository is public, and
Watch Tower protects its trademarks, so an app that looks identical could confuse people and be taken down.

**Rule of thumb: feels like home, but is clearly its own app.**

| ✅ We may match closely | ❌ We never use |
|---|---|
| A similar colour palette, light and dark | JW.ORG or JW Library logos, app icons or symbols |
| Spacing, card style and layout patterns | The names "JW", "JW.ORG" or "JW Library" in an app's name, title or icon |
| How lists, tabs and toolbars behave | JW's own font files (not licensed for other apps); we use Noto Sans |
| A calm, quick, subtle animation feel | Exact copies of their screens, artwork or illustrations |
| | Publication images or text copied from their apps or site |

Every app's README carries the independence notice from this repository's README.

Screenshots of JW Library used to match colours stay in `reference/`, which is never pushed (see `.gitignore`).
